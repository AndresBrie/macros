# Fiji-plugins-for-Retinal-Fundus
Fiji plugins for Retinal Fundus by Andres Bribiesca Sanchez


- "Open_and_overlay_fundus.ijm" opens the fundus image and black-and-white (bw) mask. It applies CLAHE directly and adjusts the binary masks correctly
- "Stop_overlay_move.ijm" stops the overlay from moving after accidental double clicks.
